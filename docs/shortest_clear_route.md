# LabMidnight 最短通关路线与地图条件检查

本文档按当前代码和 `data/floors/` 地图数据整理，不按早期 README 中“4F 黑板线索 -> 4F 配电室 -> 机房门禁卡”的旧路线理解。

当前实际最短路线是：

```text
4F 拿手电和楼梯钥匙
-> 安全出口到 3F
-> 3F 找 648 密码、保险丝、塑料卡片
-> 3F 修复配电箱
-> 3F 坐电梯到 1F
-> 1F 翻登记册，得知二楼旧连廊
-> 1F 安全出口到 2F
-> 2F 找 276 工号、旧连廊通行牌、废弃工牌
-> 2F 松开磁吸门
-> 2F 西侧安全门逃出，触发成功结局
```

## 1. 最短通关路线

### 4F：先活下来并下到三楼

1. 开局后优先找手电。
   交互提示是：`按 Space 拾取手电`。
2. 找楼梯间钥匙。
   交互提示是：`按 Space 翻找钥匙`。
3. 找安全出口，使用楼层切换，选择下到 `3F`。

注意：4F 的目标不是解完整谜题，只是拿到照明和下楼资格。

### 3F：恢复供电并坐电梯下到一楼

1. 找到密码条 `648`。
   交互提示是：`按 Space 查看...`，触发器为 `security_code_648`。
2. 用 `648` 打开三楼保安室相关门。
3. 拿保险丝。
   触发器为 `fuse_cabinet`。
4. 拿塑料卡片。
   触发器为 `plastic_card_3f`。
5. 去配电箱，用塑料卡片撬开并装保险丝。
   触发器为 `power_box`。
6. 供电恢复后，找电梯对象 `elevator`，坐电梯到 `1F`。

注意：配电箱要求同时满足 `plastic_card` 和 `fuse`，缺任意一个都会卡住。

### 1F：确认正门走不了，转去二楼旧连廊

1. 可以先检查大门外锁。
   触发器为 `lobby_main_exit_locked`，这是剧情提示，不是硬性通关条件。
2. 翻登记册。
   触发器为 `lobby_register_note`，获得 `old_corridor_note`。
3. 使用安全出口，从 `1F` 去 `2F`。

注意：严格最短路线可以直接翻登记册；检查大门外锁主要用于理解剧情。

### 2F：旧连廊最终逃离

1. 找到工号纸条 `276`。
   触发器为 `staff_code_276`。
2. 打开抽屉，获得旧连廊通行牌。
   触发器为 `maintenance_pass`。
3. 去西侧安全门交互一次。
   触发器为 `old_corridor_door`。第一次会发现磁吸卡死。
4. 拾取废弃工牌。
   触发器为 `utility_badge`。
5. 去释放开关，松开磁吸。
   触发器为 `magnet_release`。
6. 回到西侧安全门，再次交互，触发成功结局。

注意：白板和值班表是提示/干扰信息，不是最短通关必需节点。

## 3. 与早期文档路线的差异

早期 README / MVP 文档里写过一条旧主线：

```text
异常教室黑板线索 -> 保险丝 -> 配电室供电 -> 机房终端 -> 门禁卡 -> 一楼出口
```

当前地图和代码已经改成了更长的楼层逃离链路。按旧路线去找会遇到不一致：

| 旧路线节点 | 当前情况 |
|---|---|
| 4F 黑板线索 `blackboard_clue` / `note_a` | 当前 4F 有黑板装饰，但没有作为必需触发器接入最短路线 |
| 4F 机房终端 `server_terminal` | 当前最短路线不需要 4F 机房终端 |
| 最终门禁卡 `access_card` | 当前成功结局改为 2F 旧连廊链路，不依赖门禁卡 |
| 1F 直接刷卡出门 | 当前 1F 正门被锁，实际需要转去 2F 旧连廊 |

因此答辩或演示时建议按本文档路线走，避免按旧 README 路线寻找不存在的门禁卡节点。

## 4. 难度调整说明

本次已将手电容量从 `100` 提升到 `200`，新游戏初始电量也同步提升到 `200`。

对应影响：

1. 正常开手电玩到三楼时，电量压力会明显降低。
2. 电池补给量随 `FLASHLIGHT_MAX / 3` 自动提升。
3. HUD 电量条已改为按 `FLASHLIGHT_MAX` 显示，不会再按旧的 100 上限误算。
