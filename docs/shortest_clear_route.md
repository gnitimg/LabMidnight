# LabMidnight 最短通关路线与地图条件检查

本文档按当前代码和 `data/floors/` 地图数据整理。当前成功结局不再依赖早期“4F 黑板线索 -> 4F 配电室 -> 机房门禁卡 -> 1F 直接出门”的旧路线，而是走 `4F -> 3F -> 1F -> 2F 西侧旧连廊`。

## 1. 路线总览

| 顺序 | 楼层 | 目标 | 结果 |
|---:|---:|---|---|
| 1 | 4F | 拿手电 | 获得照明能力 |
| 2 | 4F | 拿楼梯钥匙 | 可使用安全出口下楼 |
| 3 | 3F | 找 648、保险丝、塑料卡片 | 准备恢复供电 |
| 4 | 3F | 修复配电箱 | 三楼供电恢复，电梯可用 |
| 5 | 3F -> 1F | 坐电梯 | 到达一楼 |
| 6 | 1F | 查正门锁、翻登记册 | 得知二楼旧连廊 |
| 7 | 1F -> 2F | 使用安全出口到二楼 | 进入最终逃离层 |
| 8 | 2F | 找 276、通行牌、工牌 | 满足旧连廊门禁条件 |
| 9 | 2F | 释放磁吸 | 西侧安全出口可打开 |
| 10 | 2F | 再次检查西侧安全出口 | 触发成功结局 |

## 5. 难度与风险

| 风险点 | 当前处理 |
|---|---|
| 手电太快没电 | `FLASHLIGHT_MAX=200`，初始 `FLASHLIGHT_START=172` |
| 蚊子干扰通关 | 同时存在上限 6，每层累计上限 6 |
| 玩家找不到二楼释放开关 | 工牌和释放开关放在西侧安全出口附近 |
| 一楼出口误以为能通关 | 交互时明确提示门外上锁 |
| 旧 README 路线误导 | README 和开发文档已改为二楼旧连廊路线 |

## 6. 答辩演示建议

| 演示目标 | 建议操作 |
|---|---|
| 展示核心技术 | 说明 Raycasting、二维地图、depth buffer、动态实体 |
| 展示主线闭环 | 直接按最短路线推进，不展示所有支线 |
| 展示蚊子系统 | 等待蚊子生成，演示嗡嗡声、追踪、点击击杀、SAN 扣减 |
| 展示结局 | 完成二楼西侧出口，观察黑场和一次性结局视频 |
