# 蚊虫动态干扰实体系统设计

## 1. 系统定位

蚊虫系统用于给 `LabMidnight（加班累了是吗）` 的黑暗探索流程增加动态压力。蚊子不是地图里的静态贴图，也不是复杂战斗怪物，而是运行时生成的二维动态实体：它会移动、追踪、发声、被屏幕点击命中，并在接近玩家时扣除 SAN。

| 设计目标 | 说明 |
|---|---|
| 增加紧张感 | 玩家不能只慢慢找路，必须处理干扰 |
| 保持课程项目规模 | 不做复杂怪物模型和大型 AI |
| 保持 Raycasting 技术路线 | 动态实体仍基于二维坐标和屏幕投影 |
| 支持课堂展示 | 能用声音、血条、追踪、点击命中解释技术点 |

## 2. 核心文件

| 文件 | 职责 |
|---|---|
| `src/systems/mosquito_system.py` | 蚊子实体、生成、状态机、寻路、攻击、空间音频 |
| `src/rendering/renderer_objects.py` | 蚊子 billboard 投影、遮挡、血条、拖尾 |
| `src/core/game.py` | 创建 `MosquitoSystem` |
| `src/core/game_floors.py` | 切楼层时重置本层蚊子 |
| `src/core/game_runtime.py` | 每帧更新蚊子并传入渲染器 |
| `src/core/game_input.py` | 鼠标左键优先攻击蚊子 |
| `assets/sounds/` | 蚊子嗡嗡、命中、死亡、叮咬音效 |
| `assets/sprites/mosquito.png` | 可选蚊子精灵，缺失时程序绘制 fallback |

## 3. 状态机

| 状态 | 进入条件 | 行为 |
|---|---|---|
| `IDLE` | 保留状态 | 不参与正常生成后的主要逻辑 |
| `WANDER` | 距离过远或寻路失败 | 随机游荡，带飞行抖动 |
| `CHASE` | 玩家在追踪范围内 | BFS 找路，叠加盘旋和冲刺 |
| `ATTACK` | 距离小于等于 `1.30` | 扣 SAN，进入攻击冷却 |
| `DEAD` | HP 小于等于 0 | 移除实体，停止相关声源 |

| 转换判断 | 当前规则 |
|---|---|
| 距离 > `MOSQUITO_TARGET_LOST_DISTANCE` | 转为 `WANDER` |
| 距离 <= `MOSQUITO_ATTACK_RANGE` | 转为 `ATTACK` |
| 其他可追踪距离 | 转为 `CHASE` |

## 4. 关键数值

| 常量 | 当前值 | 说明 |
|---|---:|---|
| `MOSQUITO_HP` | 150 | 单只蚊子生命值 |
| `MOSQUITO_MAX_ACTIVE` | 6 | 同时存在上限 |
| `MOSQUITO_MAX_PER_FLOOR` | 6 | 每层累计生成上限 |
| `MOSQUITO_SPAWN_INTERVAL_MIN` | 8.0 | 最短生成间隔 |
| `MOSQUITO_SPAWN_INTERVAL_MAX` | 15.0 | 最长生成间隔 |
| `MOSQUITO_BASE_SPEED` | 1.65 | 基础移动速度 |
| `MOSQUITO_ATTACK_RANGE` | 1.30 | 叮咬范围 |
| `MOSQUITO_ATTACK_SAN_DAMAGE` | 5 | 每次叮咬扣 SAN |
| `MOSQUITO_ATTACK_COOLDOWN` | 1.6 | 叮咬冷却 |
| `MOSQUITO_HIT_RADIUS_SCREEN` | 36 | 屏幕点击命中半径下限 |
| `MOSQUITO_VISIBLE_DISTANCE` | 16.0 | 最大可见距离 |
| `MOSQUITO_AUDIO_DISTANCE` | 12.0 | 嗡嗡声最大明显距离 |
| `MOSQUITO_TARGET_LOST_DISTANCE` | 50.0 | 超过后放弃追踪 |
| `MOSQUITO_BURST_SPEED_MULTIPLIER` | 2.20 | 冲刺倍率 |
| `MOSQUITO_LUNGE_SPEED_MULTIPLIER` | 3.00 | 近距离扑咬倍率 |

## 5. 生成逻辑

| 阶段 | 规则 |
|---|---|
| 楼层首次进入 | 首次生成延迟 2-4 秒 |
| 后续生成 | 每 8-15 秒尝试一次 |
| 潜伏点 | 每层从可通行区域选最多 6 个点 |
| 点位约束 | 距离玩家大于 4 格，点与点尽量间隔 2.5 格 |
| 优先生成 | 优先从潜伏点激活 |
| 兜底生成 | 潜伏点失败时在玩家附近可达区域生成 |

| 环境因素 | 对生成概率的影响 |
|---|---|
| 楼层 | 2F 最高，3F 次之，4F 和 1F 较低 |
| 供电恢复 | 概率乘以 `0.65` |
| 未开手电 / 没电 | 概率乘以 `1.15` |
| SAN 低于 55 | SAN 越低概率越高 |
| 最终限制 | clamp 到 `0.12 - 0.90` |

## 6. 移动与寻路

| 行为 | 实现方式 |
|---|---|
| 游荡 | 随机方向 + `sin` 抖动 |
| 追踪 | BFS 网格寻路，目标为玩家所在格 |
| 路径刷新 | 每 0.25-0.45 秒刷新 |
| 近身盘旋 | 距离近时加入轨道偏移 |
| 冲刺 | 随机触发 burst，速度短时间提升 |
| 碰撞 | 使用 `game_map.can_move_to()`，不穿墙，不穿关闭门 |

## 7. 渲染与遮挡

蚊子以世界坐标 `(x, y)` 存在，渲染时才投影到屏幕。

| 渲染步骤 | 说明 |
|---|---|
| 计算相对角度 | 根据玩家朝向判断是否在视野内 |
| 距离缩放 | 距离越近，屏幕尺寸越大 |
| 轻微浮动 | y 轴加入正弦 bob，模拟飞行 |
| depth buffer 遮挡 | 对应屏幕 ray 前方有墙或门时不绘制 |
| 血条 | 可见蚊子显示红色 HP 条 |
| 拖尾 | 最近轨迹点绘制短拖尾 |
| fallback | 没有 `assets/sprites/mosquito.png` 时程序绘制蚊子 |

## 8. 鼠标命中

| 步骤 | 规则 |
|---|---|
| 1 | 左键按下时先交给 `mosquito_system.handle_mouse_attack()` |
| 2 | 只检查可见且有 `screen_rect` 的蚊子 |
| 3 | 多只同时命中时选距离玩家最近的一只 |
| 4 | 命中后播放 `mosquito_hit` |
| 5 | HP 归零播放 `mosquito_die` 并移除 |
| 6 | 未命中蚊子时，左键继续执行普通交互 |

| 当前 SAN | 对 150 HP 蚊子的击杀次数 |
|---:|---:|
| 100 | 2 |
| 75 | 2 |
| 50 | 3 |
| 30 | 5 |

伤害规则为 `damage = int(game.player.sanity)`。攻击不额外消耗 SAN。

## 9. 空间音频

| 音频点 | 当前实现 |
|---|---|
| 主声源选择 | 活着的蚊子中威胁最高的一只 |
| 威胁评分 | 距离越近越高；可见蚊子额外加权 |
| 距离衰减 | 距离越近音量越高 |
| 左右声像 | 根据蚊子相对玩家视角的左右位置分配声道 |
| 声源停止 | 没有活蚊子或切楼层时停止 `mosquito_buzz_main` |

## 10. 与其他系统的关系

| 系统 | 关系 |
|---|---|
| SAN | 蚊子叮咬扣 SAN；SAN 越低，玩家打蚊子越弱 |
| 手电 | 不直接杀蚊子，但影响生成概率和探索压力 |
| 门 | 关闭门阻挡蚊子寻路和显示 |
| 渲染器 | 提供 depth buffer，绘制蚊子和血条 |
| 音效 | 提供空间嗡嗡声和反馈音 |
| 楼层 | 切楼层重置当前活动蚊子，但每层累计生成数保留 |

## 11. 测试表

| 测试项 | 操作 | 预期结果 |
|---|---|---|
| 生成 | 进入任意楼层等待 2-4 秒 | 首只蚊子尝试生成 |
| 追踪 | 站在开阔区域等待 | 蚊子向玩家接近 |
| 遮挡 | 关门或躲到墙后 | 蚊子不可见，不可被点中 |
| 命中 | 左键点击蚊子 | 扣蚊子 HP，显示伤害提示 |
| 击杀 | 连续点击至 HP 归零 | 蚊子消失，播放死亡音 |
| 叮咬 | 让蚊子贴近 | SAN 减少 5，播放咬击音 |
| 空间声 | 转身或绕蚊子移动 | 左右声道变化 |
| 楼层切换 | 使用电梯/安全出口 | 当前活动蚊子被清空 |

## 12. 答辩说明要点

| 角度 | 可说明内容 |
|---|---|
| 技术难点 | 动态实体与 raycasting depth buffer 结合 |
| 工程设计 | 蚊子系统独立于地图静态对象，便于关闭或调参 |
| 体验设计 | 用干扰和 SAN 压力替代复杂战斗 |
| 资源容错 | 缺精灵、缺音效不影响主流程 |
