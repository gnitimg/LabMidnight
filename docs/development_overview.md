# LabMidnight 开发文档总览

## 1. 需求定义

| 需求类型 | 当前定义 |
|---|---|
| 背景需求 | 凌晨两点，玩家从实验楼四层醒来，需要逃离异常实验楼 |
| 玩法需求 | 第一人称探索、道具收集、轻量解谜、手电管理、SAN 压力 |
| 技术需求 | 使用 Python、Pygame、Raycasting、二维地图，不使用真 3D 引擎 |
| 展示需求 | 能稳定完成一条最短通关路线，并能展示失败结局 |
| 新增需求 | 引入蚊子作为动态干扰实体，提高过程压力和技术展示点 |

## 2. 概要设计

| 模块 | 输入 | 输出 | 说明 |
|---|---|---|---|
| 核心循环 | Pygame 事件、dt | 状态更新、画面绘制 | 管理菜单、游戏、结局 |
| 地图系统 | `data/floors/` | 网格、门、物件、出生点 | 支持 1F-4F |
| 渲染系统 | 玩家位置、地图、动态实体 | 第一人称伪 3D 画面 | Raycasting + depth buffer |
| 交互系统 | 玩家视线、对象/门 | 文本、道具、flag、楼层切换 | Space/左键触发 |
| 玩家状态 | HP、SAN、电量、背包 | 失败/通关条件 | SAN 归零失败 |
| 蚊虫系统 | 地图、玩家位置、dt | 动态实体、SAN 扣减、音效 | 运行时生成和追踪 |
| 音频系统 | 事件名、声道参数 | 音效播放 | 支持空间嗡嗡声 |
| UI 系统 | 玩家状态、提示、结局状态 | HUD、背包、菜单、结局画面 | 资源缺失 fallback |

## 3. 当前主线

| 阶段 | 楼层 | 玩家目标 | 系统验证点 |
|---:|---:|---|---|
| 1 | 4F | 拿手电和楼梯钥匙 | 拾取、背包、手电 |
| 2 | 4F -> 3F | 通过安全出口下楼 | 楼层切换 |
| 3 | 3F | 收集 648、保险丝、塑料卡片 | 触发器、道具条件 |
| 4 | 3F | 修复配电箱并坐电梯 | 供电 flag、电梯 |
| 5 | 1F | 查锁、翻登记册 | 分支提示、旧连廊线索 |
| 6 | 2F | 找通行牌和工牌 | 二楼谜题链 |
| 7 | 2F | 释放磁吸并逃离 | 成功结局 |

## 4. 蚊虫系统设计摘要

| 设计点 | 方案 |
|---|---|
| 实体形式 | `Mosquito` dataclass，存在于二维地图坐标 |
| 状态 | `WANDER`、`CHASE`、`ATTACK`、`DEAD` |
| 生成 | 每层潜伏点 + 生成概率 |
| 寻路 | BFS 网格路径，关闭门阻挡 |
| 渲染 | 2.5D billboard，使用 depth buffer 遮挡 |
| 攻击玩家 | 进入 1.30 范围后扣 5 SAN |
| 玩家反击 | 鼠标左键点击可见蚊子 |
| 音效 | 单主声源空间嗡嗡声，按距离和角度变化 |

## 5. 技术难点

| 难点 | 风险 | 处理方式 |
|---|---|---|
| Raycasting 遮挡 | 动态实体可能穿墙显示 | 使用 depth buffer 判断可见性 |
| 动态实体寻路 | 太复杂会超出课程范围 | BFS 网格寻路，低频刷新 |
| 蚊子命中 | 第一人称屏幕点击和世界坐标不一致 | 渲染器写回 `screen_rect` |
| 空间音效 | 多只蚊子同时播放会混乱 | 只选择威胁最高的一只作为主声源 |
| 资源缺失 | 答辩现场缺素材可能崩溃 | 贴图、音效、视频均有 fallback |
| 通关难度 | 手电和蚊子叠加可能过难 | 手电容量提升到 200，蚊子数量设上限 |
| 结局播放 | 循环视频影响结尾体验 | 视频只播放一次，结束停最后一帧 |

## 6. 测试清单

| 类别 | 测试项 | 预期结果 |
|---|---|---|
| 启动 | `python main.py` | 进入主菜单 |
| 编译 | `python -m compileall main.py map_editor.py src` | 无语法错误 |
| 操作 | WASD、鼠标、Space、右键、B/I、F2、ESC | 与说明一致 |
| 主线 | 按最短路线推进 | 可触发成功结局 |
| 失败 | 长时间黑暗或被蚊子叮咬至 SAN 0 | 触发失败结局 |
| 蚊子生成 | 等待 2-4 秒 | 首只蚊子尝试出现 |
| 蚊子遮挡 | 关门或躲墙后 | 不可见且不可点中 |
| 蚊子攻击 | 贴近玩家 | 扣 5 SAN |
| 视频 | 成功/失败结局 | 黑场、淡入、播放一次、停最后一帧 |
